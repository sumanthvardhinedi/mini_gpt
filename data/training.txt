Topic 1: Foundations of Language Modeling and Tokenization
Language models learn statistical structure from sequential text by predicting the next token given preceding context tokens. Every modern transformer pipeline begins with tokenization, which converts raw strings into sequences of discrete integer identifiers. Word-level tokenization splits sentences along whitespace and punctuation boundaries, building a vocabulary of whole words. While simple and intuitive, word-level tokenizers struggle when encountering rare words, morphological variations, or unseen terminology during evaluation, mapping unknown strings to a fallback unknown token. Subword tokenization via Byte Pair Encoding resolves this limitation by starting from individual characters and iteratively merging the most frequent adjacent symbol pairs. Through repeated merges, Byte Pair Encoding discovers common character clusters, prefixes, suffixes, and whole words directly from the training corpus. Frequent words become single tokens, while rare words decompose gracefully into recognizable subword units. Deterministic tie-breaking during pair selection guarantees that training the Byte Pair Encoding tokenizer on the same text with the same vocabulary size always produces identical merge rules and token identifiers.

Topic 2: Dense Vector Embeddings and Positional Representations
Discrete token identifiers carry no inherent geometric meaning because adjacent integer indices do not reflect semantic similarity. A token embedding layer maps each integer index in the vocabulary to a continuous dense vector of fixed embedding dimension. During backpropagation, the embedding lookup table updates its rows so that tokens appearing in similar contexts converge toward related directions in vector space. Unlike recurrent neural networks that process tokens sequentially step by step, a transformer processes all tokens in a context window simultaneously in parallel. Because parallel matrix operations are permutation-equivariant without ordering cues, the model requires positional embeddings to distinguish token order. Learned positional embeddings assign a dedicated trainable vector to each sequence index up to the maximum context window length. Summing the token embedding tensor and the positional embedding tensor produces position-aware input representations of shape batch size by sequence length by embedding dimension.

Topic 3: Scaled Dot-Product Self-Attention and Causal Masking
Self-attention enables every token position in a sequence to gather contextual information from relevant tokens across the context window. From the input representation tensor, three distinct linear projections compute query vectors, key vectors, and value vectors. The dot product between queries and transposed keys measures compatibility scores between token pairs. Dividing raw attention scores by the square root of the head dimension prevents large dot products from pushing the softmax function into regions with vanishingly small gradients. In a decoder-only language model such as MiniGPT, causal masking is essential to preserve the autoregressive property during training. An upper-triangular causal mask fills future token positions above the main diagonal with negative infinity prior to softmax normalization. After softmax normalization, attention weights over future positions become strictly zero, ensuring that the prediction at any position depends only on past and present tokens. Multi-head self-attention splits the embedding dimension across multiple parallel heads so the network can attend to syntactic structure, local lexical patterns, and long-range semantic dependencies simultaneously.

Topic 4: Transformer Decoder Blocks and Residual Pathways
A complete decoder transformer block combines multi-head causal self-attention with a position-wise feed-forward network, layer normalization, and residual skip connections. Pre-normalization applies layer normalization across the embedding dimension before each sub-layer, stabilizing activation magnitudes across deep stacks of transformer blocks. Residual connections add the sub-layer output directly back to its unmodified input, creating an unimpeded gradient highway from the loss function back to the earliest embedding layers. Following the attention sub-layer, the position-wise feed-forward network expands the representation to a wider hidden dimension, applies a smooth Gaussian Error Linear Unit activation function, and projects back to the model embedding dimension. Stacking multiple decoder blocks allows hierarchical feature extraction: early layers capture local token relationships and phrase boundaries, while deeper layers synthesize broader context across the sequence. A final layer normalization and linear language model head project the contextualized hidden states to vocabulary logits for next-token prediction.

Topic 5: Optimization, Cross-Entropy Loss, and Perplexity Metrics
Training a decoder language model frames next-token prediction as multi-class classification over the vocabulary at every sequence position. Given a stream of token identifiers, a sliding-window dataset extracts input sequences of fixed context length and target sequences shifted right by exactly one position. During the forward pass, the model produces unnormalized logits for every batch item and sequence step. Cross-entropy loss compares the predicted probability distribution against the ground-truth next token identifier. The AdamW optimizer updates trainable weights using adaptive first and second gradient moments combined with decoupled weight decay regularization. Perplexity, defined as the exponential of the cross-entropy loss, provides an interpretable measure of predictive uncertainty representing the effective branching factor of the model distribution. Lower cross-entropy loss and lower perplexity indicate stronger predictive confidence on training and validation sequences. Saving model checkpoints with optimizer state, configuration parameters, and tokenizer merge rules ensures that training experiments remain reproducible and verifiable.

Topic 6: Autoregressive Text Generation and Sampling Strategies
Once trained, a decoder-only transformer generates new text autoregressively one token at a time. Starting from a prompt string encoded by the tokenizer, the model performs a forward pass in evaluation mode with gradient tracking disabled. Only the logits at the final sequence position are needed to select the next token. Greedy decoding deterministically picks the token with the maximum logit value at every step, producing repeatable continuations. For more varied generation, temperature scaling divides the logits before softmax normalization: temperatures below one sharpen the distribution toward high-probability tokens, while temperatures above one flatten the distribution to encourage exploration. Top-k sampling restricts candidate selection to the k highest-scoring vocabulary tokens by masking all remaining logits to negative infinity before renormalizing probabilities. Whenever the growing sequence exceeds the configured maximum context length, the generation loop crops the input tensor to retain only the most recent tokens within the context window.

Topic 7: Scientific Computing, Linear Algebra, and Numerical Stability
Deep learning systems rely on fast, numerically stable tensor operations implemented over multidimensional arrays. Matrix multiplication forms the computational core of linear projections, attention score calculation, and feed-forward layers. Maintaining numerical stability requires careful attention to floating-point scale throughout forward and backward passes. In softmax and cross-entropy computations, subtracting the maximum logit before exponentiation prevents exponential overflow without altering the resulting probability distribution. Similarly, when computing perplexity from cross-entropy loss, clamping extreme loss values guards against floating-point overflow during early training steps. Layer normalization computes per-token mean and variance across feature channels and adds a small epsilon constant inside the square-root denominator so division never encounters zero variance. Deterministic random number generation across Python, NumPy, and PyTorch guarantees that weight initialization, dataset batching, and stochastic sampling behave identically across repeated experimental runs.

Topic 8: Information Theory, Entropy, and Sequence Compression
Information theory provides the mathematical foundation for both subword tokenization and autoregressive language modeling. Shannon entropy quantifies the average amount of surprise or information content carried by symbols drawn from an underlying probability distribution. Byte Pair Encoding compresses raw text by replacing frequent character pairs with single vocabulary symbols, reducing sequence length while balancing vocabulary size against token granularity. Language modeling minimizes the cross-entropy between the empirical distribution of training sequences and the probability distribution predicted by the transformer network. When cross-entropy loss approaches the true entropy of the text source, the model assigns high probability to plausible continuations and low probability to unlikely token transitions. Evaluating cross-entropy loss and perplexity on a held-out validation split verifies that the transformer generalizes learned patterns beyond memorized training windows.
